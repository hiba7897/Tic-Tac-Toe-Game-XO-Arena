XO Arena
A modern, responsive Tic-Tac-Toe game built with React.

About the Project:
XO Arena is an interactive Tic-Tac-Toe application featuring two-player gameplay, a computer opponent powered by the Minimax algorithm, customizable player symbols, and a persistent scoreboard.

The application includes a modern dark and light theme and saves game information using browser localStorage.

Features:
- Two-player mode
- Player versus computer mode
- Computer opponent using the Minimax algorithm
- Player symbol selection (X or O)
- Automatic turn management
- Win and draw detection
- Highlighted winning combinations
- Participant-based scoreboard
- Play Again and Reset Scores controls
- Dark and light themes
- Game progress persistence using localStorage
- Responsive desktop, tablet, and mobile layouts
- Accessible interactive controls


Technologies Used:
- React
- JavaScript
- JSX
- HTML5
- CSS3
- Vite
- Browser localStorage

Installation:
1. Clone or download the project.
2. Open the project folder in your terminal.
3. Install dependencies:
    - npm install
4. Start the development server:
    - npm run dev
5. Open the local URL displayed in your terminal.
